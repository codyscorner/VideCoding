# Games

A collection of browser-based and Unity arcade games.

## Projects

### Falcon 9 Lander

Two complete implementations of a Falcon 9 rocket booster landing simulation.

| Version | Location | How to Play |
|---------|----------|-------------|
| HTML5 | `Falcon9Lander-HTML5/` | Open `index.html` in any browser — no install needed |
| Unity | `Falcon9Lander-Unity/` | Open in Unity Hub as a 2D project |

**Controls:** W/S — throttle | A/D — grid fins | SPACE — engine on/off | L — deploy legs

**4 difficulty levels:** The Grasshopper, Return to Launch Site, Of Course I Still Love You, Falcon Heavy Center Core

See `Falcon9-Lander-Project-README.md` for full gameplay guide and physics details.

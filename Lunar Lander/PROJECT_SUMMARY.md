# Lunar Lander

**Version:** 1.0.0 | **Status:** Complete | **Type:** HTML5 Browser Game

A single-file HTML5 Lunar Lander game that runs in any modern browser. No server or install required.

## Gameplay

- Control a lunar lander descending toward the moon surface
- Use thrusters to slow descent and steer
- Land safely on designated pads — land too fast or at an angle and you crash
- Fuel is limited

## Tech Stack

- Pure HTML5 / JavaScript / Canvas
- Single self-contained file: `lunar_lander_game.html`

## Usage

Open `lunar_lander_game.html` in any modern web browser.

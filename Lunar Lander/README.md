# Lunar Lander

A classic lunar lander game in a single self-contained HTML5 file. No installation or server required — just open in a browser and play.

## How to Play

Open `lunar_lander_game.html` in any modern web browser.

## Controls

| Key | Action |
|-----|--------|
| Up Arrow / W | Fire thruster |
| Left Arrow / A | Rotate left |
| Right Arrow / D | Rotate right |
| R | Restart |

## Objective

Guide the lander to a safe touchdown on the surface. Land with low velocity to succeed — come in too fast and you'll crash.

## Requirements

Any modern web browser. No Python, no server, no dependencies.

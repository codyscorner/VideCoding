# Changelog

## v1.6.0 (2026-07-08)

- Flexible frame selection: Last Frame, Frame Number, Percent of Duration, Timestamp (mm:ss/hh:mm:ss/seconds), or Every N Seconds (Multiple).
- Contact sheet mode: combine all frames from "Every N Seconds" mode into a single grid image per video, instead of one file per frame.
- Frame preview: "Preview Frame" button shows the selected frame from the first matching video in the source folder before running the full batch.
- Output format choice: PNG or JPG, with an adjustable JPG quality slider (1-100).
- Settings migration: existing `frame_number` config values are automatically mapped to the new selection-mode fields on first load.

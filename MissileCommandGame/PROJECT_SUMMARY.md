# Missile Command Game

**Version:** 1.1.0 | **Status:** Complete | **Type:** HTML5 Browser Game

A browser-based recreation of the classic Missile Command arcade game. No install required — runs in any modern browser.

## Gameplay

- Defend your cities from incoming missiles
- Click to launch counter-missiles that detonate in mid-air
- Destroy all incoming missiles before they reach the ground
- Multiple waves with increasing difficulty
- Easy/Normal/Hard difficulty (affects enemy missile spawn rate and speed, and starting ammo)
- Press **P** (or Escape) to pause/resume
- Top-5 high score table persisted in the browser (localStorage)
- Sound effects toggle (Web Audio API beeps, no external audio files)
- Click anywhere on the canvas after Game Over to restart

## Tech Stack

- HTML5 / JavaScript / Canvas / Web Audio API
- Files: `index.html`, `main.js`

## Usage

Open `index.html` in any modern web browser.
